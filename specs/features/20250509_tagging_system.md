Currently, we have fixed categories. This could limit users. Replacing this with tags would open a lot of possibilities:

1. Enable user to tag expenses as they please.
2. Extend existing features like Travel mode by allowing users to tag the expenses with a specific tag associated to a travel e.g. “Tokyo 2025“
3. Avoid decision paralysis on what Categories should be available, when there’s this another option of going with freeform tags.

Requirements:

- A tag section in the Expense editing forms and Expense display components. The tag section acts both as a display for the Tags of the Expense, and a way for the users to add more tags by typing in.
- When users type in the Tag they wanna add in, autosuggestions based on their existing tags are displayed that they can click.
- Upon creation of a new expense, they are not automatically tagged. Suggestions for tags will be displayed on the Tags section of the Expense display, where users can choose to add the Tag suggestions or add their own.
- Tag Suggestions are to be shown above the Tag field and clicking on the Tag Suggestions would add it to the Expense.
